1. Replace the listed source files in your existing repository with the files from this archive.
2. Copy the new `public/assets/props`, `public/assets/sprites`, `public/assets/ui` folders and the updated `public/assets/manifest.json`.
3. Run:
   - `npm install` (if needed)
   - `npm run build`
   - `npm test`
4. For static deployment you can upload the included `dist/` folder directly.
5. Read `docs/IMPLEMENTATION_STATUS.md` before calling the patch fully complete; several systems are marked honestly as PARTIAL / NOT DONE.
