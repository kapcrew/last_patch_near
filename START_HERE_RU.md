# THE LAST PATCH — полный пакет v3

Это **единый проект**, а не patch-only архив. Содержит исходники, графику, локальную игру, исходники Rust-контракта, документы, тесты и уже сгенерированный статический `dist/`.

## Быстрый запуск готовой игры на Mac / Linux

Требуется Node.js 20+.

```bash
cd the-last-patch
npm ci --offline
npm test
npm start
```

Откройте `http://localhost:8080/sample` для игры без кошелька. Если порт занят, `PORT=8765 npm start`.

## Статический сайт

Готовая сборка находится в `dist/`. Её можно целиком загрузить на статический HTTPS-хостинг; хостинг должен отдавать `index.html` для путей `/sample`, `/live` и других SPA-роутов.

## Отдельный режим NEAR Testnet

`/live` — отдельный режим. Без настоящего `contractId` в `dist/config.json` он не производит реальные выплаты. Не путайте story Sparks с testnet NEAR. Прочитайте `docs/DEPLOY_TESTNET.md`. Исходники Rust в `contracts/bounty/`; контракт в этой поставке не развёрнут и не подтверждён транзакциями.

## Важные ограничения

Переходы по сюжетным заданиям и мини-игры включены, но 90–120 минут прохождения не подтверждены плейтестами. Реализована не вся глубина MASTER_TZ: нет полноценного A* пути, публичного серверного рейтинга и полного E2E-контракта. Подробный статус — в `docs/IMPLEMENTATION_STATUS.md`.

## Состав

- `src/` — TypeScript-код, включая story campaign и NEAR/GitHub адаптеры
- `public/` — используемые графические файлы и manifest
- `dist/` — готовая статическая браузерная сборка
- `contracts/bounty/` — исходный Rust/near-sdk escrow + тесты (не проверены в этом цикле)
- `tests/` — локальные unit-тесты
- `docs/` — исходные документы и статус реализации
- `docs/game-v3-spec/` — новое полное ТЗ, 32 сюжетных + 16 побочных квестов, QA и перечень ассетов
- `github-fixture/` — тестовый репозиторий для реального GitHub issue/PR
