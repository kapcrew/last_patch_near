# Decisions and deviations (2026-11-14)

1. **Missing mandatory starter ZIP:** The uploaded files were `THE_LAST_PATCH_MASTER_TZ_RU(1).md`, `THE_LAST_PATCH_FULL_TZ_NEAR(1).pdf`, `pixudi_front(1).zip` and `starfall.zip`. The required `THE_LAST_PATCH_NEAR_Standalone_Starter.zip` was not in the uploaded files and was not located through available connected search. The Cursor master prompt was retrieved from the user's file Library. **Deviation:** reconstructed the game from the detailed source description instead of patching unseen `src/app.mjs`, `src/logic.mjs` and five original tests. The new 8 tests are not the original five.
2. **Static TypeScript build:** Vite could not be installed due container DNS blockage; the global TypeScript compiler was present. A local unmodified TypeScript 5.8.3 npm tarball was vendored with its Apache-2.0 license and `package-lock.json` generated; `npm ci --offline` now PASS. `npm run build` uses `tsc` to emit ES modules and copies static assets. This produces deployable `dist/` without build-time network; a Vite build is a later compatibility item, not a claim.
3. **No local Rust toolchain:** Rust `cargo` was not available, and package download was unreachable. Wrote near-sdk 5.17.2 code and unit tests with no compile claim. `Cargo.lock` cannot be generated offline; the deployment guide requires it and the release gate rejects missing lockfile.
4. **Art provenance:** Inspected Pixudi/Starfall archive names. Did not merge art or source wholesale (license/fit not verified). Created fresh custom pixel-art twilight background; generated image has no game logic embedded. `AssetRegistry` accepts user-provided art later, while missing assets fall back to procedural primitives.
5. **Viewport:** doubled original documented 320×180 logical canvas to 640×360 for clarity and paths. 16:9 and pixelated rendering maintained; coordinates are adjustable game metadata, not financial state.
6. **Escrow reserve:** Fixed **0.08 NEAR** in addition to reward, exact transfer required. Reserve is permanently retained as contract storage/operations collateral, explicitly disclosed. Open bounty cancellation refunds **reward only**. This fixed-reserve policy must be measured with Rust/sandbox storage tests before funds are attached; otherwise block release.
7. **Live funding:** Bridge is the only live quest. Well, Library and Forge are marked Sample, as allowed by P0. They do not contribute to live payout total or health.
8. **GitHub P0 fixture:** `github-fixture/` has an intentionally broken router test and instructions for publishing an actual GitHub issue and PR. No external GitHub resources were created or claimed.
9. **AI scope:** Only deterministic issue-grounded fallback, no pretend AI cloud access or approval power. A provider integration is postponed until real P0 economy passes.
10. **Wallet scope:** Wallet Selector v10 MyNearWallet adapter imports pinned CDN modules at interaction time. Browser/testnet signing was not exercised; local contract and UI cannot be judged complete until this is done.
11. **No secret keys:** Public `dist/config.json` only. Account creation, contract deploy, GitHub publishing and hackathon submission must be authorized by the owner on their own machine.
12. **No browser screenshot claim:** Chromium/Playwright navigation was blocked by sandbox `ERR_BLOCKED_BY_ADMINISTRATOR`; a constrained browser test imported the real compiled JS as Blob modules with a temporary `/sample` override. It passed visual DOM checks, four local sample transitions, keyboard, canvas taps and 320px mobile width; see `docs/logs/ui-smoke.log`. Actual localhost routing, wallet and testnet E2E remain untested.
